# VU Exam Summative Exporter

สกิลสำหรับเชื่อมต่อและดึงข้อมูลผลการสอบ คะแนนนักศึกษารายบุคคล คำตอบที่เลือก (ถูก/ผิด) และค่าสถิติวิเคราะห์คุณภาพข้อสอบ (Difficulty Index $p$ และ Discrimination Index $r$) จากระบบ **VU Exam Manage Summative** (`https://i.vu.ac.th/exam-manage-summative/`) ออกมาเป็นรายงาน Excel คุณภาพสูง 5 แผ่นงาน

---

## 🚀 สรุปขั้นตอนการทำงาน (Workflow)

สกิลนี้รองรับ 2 รูปแบบการใช้งาน:

### โหมดที่ 1: Interactive Wizard (ถามทีละขั้น - แนะนำสำหรับผู้ใช้ทั่วไป)

หากผู้ใช้ไม่ได้ระบุรหัสหรือชื่อการสอบมาชัดเจน ให้ปฏิบัติตามลำดับขั้นดังนี้:

1. **ดึงรายวิชาและภาคเรียน**:
   เรียกใช้คำสั่งเพื่อดูรายวิชาที่บัญชีมีสิทธิ์เข้าถึง:
   ```bash
   python .agents/skills/vu-exam-exporter/scripts/vu_cli.py list-subjects
   ```
   จากนั้นแสดงรายการภาคเรียนและวิชาให้ผู้ใช้เลือก (1, 2, 3...)

2. **ดึงรายการชุดข้อสอบของวิชานั้น**:
   เมื่อผู้ใช้เลือกวิชา ให้ใช้ `semid` และ `subjectid` ของวิชานั้นมาดึงรายการสอบ:
   ```bash
   python .agents/skills/vu-exam-exporter/scripts/vu_cli.py list-exams --semid <SEMID> --subjectid <SUBJECTID>
   ```
   แสดงรายการชุดข้อสอบ (เช่น Midterm, Final, Re-Test) พร้อมคะแนนเต็มให้ผู้ใช้เลือก

3. **ดำเนินการดึงข้อมูลและสร้างไฟล์ Excel**:
   เมื่อได้ `exam_id` แล้ว ให้รันคำสั่ง export:
   ```bash
   python .agents/skills/vu-exam-exporter/scripts/vu_cli.py export --exam-id <EXAM_ID>
   ```
   ระบบจะดึงคะแนนของผู้เข้าสอบทุกคน, รายละเอียดคำตอบทุกข้อ, ค่าวิเคราะห์ $p$ และ $r$ และสร้างไฟล์ Excel สรุป 5 แผ่นงานโดยอัตโนมัติ

---

### โหมดที่ 2: Quick Command (ดึงทันทีเมื่อทราบข้อมูล)

หากผู้ใช้ระบุรหัสการสอบ (`exam_id`) หรือระบุชื่อวิชาและรอบสอบมาชัดเจนในคำสั่งเดียว:
- หากทราบ `exam_id` ให้ข้ามไปรันคำสั่ง export ทันที:
  ```bash
  python .agents/skills/vu-exam-exporter/scripts/vu_cli.py export --exam-id <EXAM_ID>
  ```
- หากผู้ใช้ระบุชื่อวิชา ให้รัน `list-subjects` แบบ `--json` ในเบื้องหลังเพื่อหา `semid` และ `subjectid` ที่ตรงกัน แล้วตามด้วย `list-exams` และ `export` ทันที

---

## 📑 รายละเอียดแผ่นงานในไฟล์ Excel ที่สร้าง (5 Sheets)

1. **`สรุปภาพรวม`**: ตารางคะแนนรวมของนักศึกษาทุกคน, เวลาเริ่มสอบ, เวลาส่งข้อสอบ, ระยะเวลาที่ใช้, และกล่องสถิติรวม (คะแนนเฉลี่ย Mean, ค่าสูงสุด Max, ค่าต่ำสุด Min, ส่วนเบี่ยงเบนมาตรฐาน S.D.)
2. **`วิเคราะห์รายข้อ (p, r)`**: ตารางสถิติข้อสอบรายข้อ พร้อมโจทย์, เฉลยที่ถูกต้อง, คำอธิบายเฉลย, จำนวนคนตอบถูก/ผิด, ค่าความยาก ($p$), ระดับความยาก, ค่าอำนาจจำแนก ($r$), ระดับอำนาจจำแนก, และคำแนะนำเชิงคุณภาพ
3. **`เมทริกซ์คะแนน (1 หรือ 0)`**: ตาราง Matrix แสดงผลคะแนนรายข้อของนักศึกษาทุกคน (1 = ถูก ไฮไลท์เขียว, 0 = ผิด ไฮไลท์ส้ม) พร้อมแถวสรุปจำนวนคนและร้อยละความถูกต้องท้ายตาราง
4. **`เมทริกซ์ตัวเลือกที่ตอบ`**: ตาราง Matrix แสดงข้อความตัวเลือกที่นักศึกษาแต่ละคนเลือกตอบจริงในแต่ละข้อ พร้อมระบุสัญลักษณ์ `✓` (ถูก) หรือ `✗` (ผิด)
5. **`รายละเอียดข้อสอบและคำตอบ`**: แสดงโจทย์เต็ม ตัวเลือกทั้งหมด A, B, C, D เฉลย และคอลัมน์ของนักศึกษาทุกคนเทียบเคียงกัน ให้เห็นว่าใครเลือกตอบตัวเลือกไหนพร้อมคะแนนรายข้ออย่างชัดเจน

## ⚙️ การตั้งค่าบัญชีผู้ใช้ (Credentials)

เครื่องมือรองรับการกำหนด Username และ Password ผ่าน 3 ช่องทางตามลำดับความสำคัญ:
1. Command Line Flag: `--username <user> --password <pass>`
2. Environment Variables: `VU_EXAM_USERNAME` และ `VU_EXAM_PASSWORD`
3. ค่าเริ่มต้นในระบบ (Default Fallback)
