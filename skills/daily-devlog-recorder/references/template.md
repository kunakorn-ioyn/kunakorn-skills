# 📑 Daily Devlog & Changelog Standards

This reference defines the standard template and formatting requirements for daily devlogs generated by `daily-devlog-recorder`.

---

## 1. Daily Devlog File Path Specification

Devlogs MUST be saved in a structured, month-partitioned folder structure:

```
docs/devlogs/
├── 2026-09/
│   ├── 2026-09-28.md
│   ├── 2026-09-29.md
│   └── README.md (Monthly Index)
└── 2026-10/
    └── 2026-10-01.md
```

If the project uses an alternative documentation folder (e.g. `02_Execution/devlogs/` or `.codex/devlogs/`), adapt to the project's convention while maintaining the `YYYY-MM/YYYY-MM-DD.md` naming convention.

---

## 2. Standard Devlog Template (`YYYY-MM-DD.md`)

```markdown
# 📝 Daily Devlog — YYYY-MM-DD

> **Project:** [Project Name / Short Title]  
> **Date:** [Day of week, DD Month YYYY (e.g., วันอังคารที่ 29 กันยายน 2569)]  
> **Git Branch:** `[branch-name]`  
> **Total Files Modified:** [N] files  
> **Git Commits Today:** [N] commits
```
