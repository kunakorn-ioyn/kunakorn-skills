# คู่มือมาตรฐานโครงสร้างเล่มโครงงานปริญญานิพนธ์ 5 บท (Thai Capstone Thesis Guide)

## 1. ข้อกำหนดรูปแบบและข้อความวิชาการ (Formatting & Academic Tone)

1. **ฟอนต์และขนาดตัวอักษร**:
   - ภาษาไทยและอังกฤษ: `TH Sarabun New`
   - ชื่อบท / หัวข้อหลักระดับ 1: `18pt หนา` จัดกึ่งกลางหน้ากระดาษ
   - หัวข้อระดับ 2 (`1.1`, `1.2`): `16pt หนา` ชิดซ้าย
   - หัวข้อระดับ 3 (`1.1.1`): `16pt หนา` ชิดซ้าย
   - เนื้อหาทั่วไป: `16pt ปกติ` ย่อหน้าเยื้อง `0.5 นิ้ว` (1.27 ซม.)
2. **สีตัวอักษร**: สีดำล้วนบริสุทธิ์ (`RGB: 0, 0, 0`) ห้ามใช้สีน้ำเงิน เขียว แดง หรือสีแฟนซีในเนื้อหา
3. **ระยะขอบหน้ากระดาษ (Margins)**:
   - ด้านซ้าย (Left Margin): `1.5 นิ้ว` (3.81 ซม.) เพื่อเว้นระยะสำหรับการเข้าเล่ม / เย็บเล่ม
   - ด้านบน (Top): `1.0 นิ้ว` (2.54 ซม.)
   - ด้านขวา (Right): `1.0 นิ้ว` (2.54 ซม.)
   - ด้านล่าง (Bottom): `1.0 นิ้ว` (2.54 ซม.)
4. **ตารางและเส้นขอบ**:
   - รูปแบบตารางวิชาการ: เส้นขอบบนทึบ 1 เส้น, เส้นขอบล่างของแถวหัวตารางทึบ 1 เส้น, เส้นขอบล่างสุดของตารางทึบ 1 เส้น
   - **ห้ามมีเส้นขอบแนวตั้ง** (No vertical borders) ทั้งด้านข้างและด้านใน
   - แถวหัวตารางใช้พื้นหลังสีเทาอ่อนมาก (`#F3F4F6`) หรือสีขาว
5. **การใช้ภาพประกอบและคำบรรยาย**:
   - จัดภาพกึ่งกลางหน้ากระดาษ ความกว้างประมาณ 5.0 - 5.5 นิ้ว
   - มีคำบรรยายใต้ภาพกึ่งกลาง เช่น `รูปที่ 4.1 แสดงหน้าจอ...`
   - ต้องมีข้อความอธิบายองค์ประกอบใต้ภาพทุกรูปเสมอ เช่น `จากรูปที่ 4.1 แสดงหน้าจอ... ประกอบด้วย 1)... 2)... 3)...`
6. **กฎเหล็ก (Anti-Patterns)**:
   - **ZERO EMOJIS**: ห้ามมีอิโมจิหรือสัญลักษณ์กราฟิกหลุดเข้ามาในเอกสารเด็ดขาด
   - **NO RAINBOW CALLOUT BOXES**: ห้ามใส่กล่องเน้นข้อความขอบหนาสีฟ้า/สีม่วงแบบ AI ทั่วไป

## 2. โครงสร้างเนื้อหา 5 บทมาตรฐาน

### หน้าปกและส่วนต้น (Cover & Preliminary)
- **หน้าปกนอก / ปกใน**: ชื่อโครงงานภาษาไทยและอังกฤษ, คณะผู้จัดทำ, อาจารย์ที่ปรึกษา, คณะ, สถาบัน, ปีการศึกษา
- **บทคัดย่อภาษาไทย**: วัตถุประสงค์, วิธีดำเนินงาน/เทคโนโลยี, ผลลัพธ์สำคัญ, สถิติความพึงพอใจ
- **Abstract (ภาษาอังกฤษ)**: English translation of the abstract.

### บทที่ 1: บทนำ (Introduction)
- **1.1 ที่มาและความสำคัญของปัญหา**: บริบทขององค์กร, ปัญหาของวิธีเดิม (Excel/Manual), คอขวด, ผลกระทบ
- **1.2 วัตถุประสงค์ของโครงงาน**: 1.2.1 เพื่อศึกษา..., 1.2.2 เพื่อพัฒนา..., 1.2.3 เพื่อประเมิน...
- **1.3 ประโยชน์ที่คาดว่าจะได้รับ**: 1.3.1 ด้านประสิทธิภาพ, 1.3.2 ด้านความถูกต้อง, 1.3.3 ด้านบุคลากร
- **1.4 ขอบเขตของโครงงาน**: กลุ่มตัวอย่าง (n ท่าน), ขอบเขตเชิงหน้าที่ (Functional Scope), ขอบเขตเทคโนโลยี
- **1.5 ขั้นตอนและแผนการดำเนินงาน**: ตาราง Gantt Chart 5 เดือน (ตารางที่ 1.1)

### บทที่ 2: เอกสารและงานวิจัยที่เกี่ยวข้อง (Literature Review)
- **2.1 ทฤษฎีและแนวคิดหลัก**: ทฤษฎีการจัดตาราง, อัลกอริทึม Constraint Optimization, ปัญหา NP-Hard
- **2.2 การทบทวนวรรณกรรมและการเปรียบเทียบระบบ**: ตารางเปรียบเทียบ 5 ระบบ (ตารางที่ 2.1)
- **2.3 กฎเกณฑ์และข้อบังคับเฉพาะทาง**: สูตรการคำนวณภาระงาน, เกณฑ์สภาวิชาชีพ
- **2.4 สถาปัตยกรรมและเทคโนโลยีที่ใช้**: Backend, Database, Frontend, Authentication, API Integration

### บทที่ 3: วิธีการดำเนินงานและการออกแบบระบบ (System Design)
- **3.1 การวิเคราะห์ความต้องการ**: Functional Requirements & Non-Functional Requirements
- **3.2 ตารางวิเคราะห์กระบวนการทำงานหลัก**: ตารางที่ 3.1 Process Specification (P1.0 ถึง P5.0)
- **3.3 แผนภาพกระแสข้อมูล (DFD)**:
  - รูปที่ 3.1 แผนภาพบริบท (Context Diagram DFD Level 0) พร้อมคำอธิบาย
  - DFD Level 1 แสดงกระบวนการย่อย 1.0 ถึง 5.0
- **3.4 แผนภาพกิจกรรม (Activity Diagrams)**
- **3.5 พจนานุกรมข้อมูล (Data Dictionary)**:
  - **สร้างตารางแยกสำหรับทุกตารางฐานข้อมูล** (ตารางที่ 3.2 ถึง 3.X)
  - คอลัมน์: ลำดับ, ชื่อฟิลด์, ประเภทข้อมูล, ข้อจำกัด/คีย์, คำอธิบาย
- **3.6 แผนภาพความสัมพันธ์ของข้อมูล (ERD)**: รูปที่ 3.2 ER Diagram พร้อมอธิบาย Referential Integrity

### บทที่ 4: ผลการดำเนินงานและการทดสอบระบบ (Implementation & Testing)
- **4.1 ผลการพัฒนาระบบส่วนติดต่อประสานผู้ใช้ (UI Walkthrough)**:
  - แคปเจอร์ภาพหน้าจอจริงของระบบครบทุกหน้า (รูปที่ 4.1 ถึง 4.10+)
  - แต่ละหน้าต้องระบุปุ่มกด, ฟิลด์กรอกข้อมูล, ตาราง, และการตอบสนองของระบบอย่างละเอียด
- **4.2 การทดสอบระบบและการประกันคุณภาพ (Black-box Test Matrix)**:
  - ตารางที่ 4.1 ผลการทดสอบ 12 กรณีทดสอบ (TC-01 ถึง TC-12) แสดงผลลัพธ์ที่คาดหวังและผลจริง
- **4.3 ผลการประเมินความพึงพอใจของผู้ใช้งาน**:
  - ตารางที่ 4.2 ผลประเมินกลุ่มผู้ใช้งานทั่วไป (ค่าเฉลี่ย x̄, ส่วนเบี่ยงเบนมาตรฐาน S.D., ระดับความพึงพอใจ)
  - ตารางที่ 4.3 ผลประเมินกลุ่มผู้ดูแลระบบและผู้ประสานงาน
  - ตารางที่ 4.4 ตารางเปรียบเทียบก่อน-หลังการพัฒนาระบบ (Before vs After)

### บทที่ 5: สรุปผล อภิปรายผล และข้อเสนอแนะ (Conclusion & Discussion)
- **5.1 สรุปผลการดำเนินงาน**: สรุปเปรียบเทียบกับวัตถุประสงค์ข้อ 1.2.1-1.2.3
- **5.2 อภิปรายผลการดำเนินงาน**: อภิปรายทางวิศวกรรม เหตุผลที่เลือกสถาปัตยกรรม Modular Monolith
- **5.3 ปัญหา อุปสรรค และแนวทางแก้ไข**: ปัญหาทางเทคนิคที่พบ (Browser cache, Security, Null guards) และวิธีแก้
- **5.4 ข้อเสนอแนะในการพัฒนาครั้งต่อไป**: แผนงานในอนาคต (WebSockets, Registrar API, AI Assistant)

- **ภาคผนวก ข**: โครงสร้างคำสั่ง SQL สำหรับสร้างฐานข้อมูล (DDL Schema Excerpt)
